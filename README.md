# Swara Chaudhari - Portfolio Website

## 🌟 Key Features

- **Dark Theme by Default**: Obsidian and slate palette (`#0b0f17`) with vibrant cyan (`#38bdf8`), indigo (`#818cf8`), and emerald accents. Optional light-mode toggle with preference saved in `localStorage`.
- **Smooth Animations**:
  - Scroll-reveal animations for sections, project cards, and timelines using `IntersectionObserver`.
  - Floating badges with varied CSS `@keyframes` floats.
  - Interactive 3D tilt effect on the hero profile card.
  - Animated counting numbers for academic milestones (CGPA 8.09, SSC 92.20%).
  - Ambient glowing orbs and rotating orbital rings.

## 🚀 How to Run

1. Simply double-click `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).
2. Alternatively, run a local web server (e.g. `npx serve`, Python `python -m http.server 8000`, or VS Code Live Server).
