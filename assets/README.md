# Assets Folder Instructions

Place your custom personal files in this directory:

### 1. 📷 Profile Picture
- File name: `profile.jpg` (or `.png`)
- Location: `assets/profile.jpg`
- **Behavior**: If `assets/profile.jpg` is present, it will automatically show on your interactive profile card and the "About Me" section. If no picture is found, the website gracefully falls back to your stylish glowing **SC** initials!

---

### 2. 📄 Resume PDF
- File name: `Swara_Chaudhari_Resume.pdf`
- Location: `assets/Swara_Chaudhari_Resume.pdf`
- **Behavior**: Clicking "Download Resume" in the navigation bar, hero section, or footer will immediately download this PDF.

---

### 3. 🔗 Social Links (LinkedIn & GitHub)
To update your exact LinkedIn or GitHub usernames, open [index.html](../index.html) and replace:
- `https://linkedin.com/in/swarachaudhari` with your real LinkedIn profile URL.
- `https://github.com/swarachaudhari` with your real GitHub profile URL.
